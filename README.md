# Sagar - Electronics Engineering & IoT Portfolio Website

A modern, responsive, and student-friendly portfolio website specifically tailored for an Electronics Engineering Diploma student at **Government Polytechnic, Patna 7 (SBTE Bihar)**.

## 🚀 Features & Structure

1. **Header / Hero Section**:
   - Name: **Sagar**
   - Title: Electronics Engineering Student | Tech & IoT Enthusiast
   - College Highlight: **Government Polytechnic, Patna 7 (GP Patna 7) - SBTE Bihar**
   - Quick action CTA buttons, dynamic statistics counter, and animated electronic core avatar.

2. **Academic Profile / Syllabus Knowledge (Structured Cards)**:
   - Branch: Diploma in Electronics Engineering
   - Core SBTE Bihar Subjects:
     - *Electronic Devices and Circuits (EDC)*
     - *Digital Electronics & Logic Design*
     - *Microprocessors & Microcontrollers (8085, Arduino, ESP32)*
     - *Power Electronics & Industrial Automation*
     - *Communication Engineering*

3. **Practical Projects & Circuits**:
   - **Auto-cut Inverter** (Power Electronics & Relay Control)
   - **Audio Amplifier Circuit** (Analog Circuit Design & Transistors)
   - **IoT-based Smart Systems** using Arduino & ESP32 (Microcontroller Programming & Wireless Control)

4. **Technical Skills & Tools**:
   - Hardware: Breadboarding, Precision Soldering, Multimeter testing, Circuit Troubleshooting
   - Software/Coding: Embedded C (Arduino IDE), ESP32 / AVR, Basic PCB Design concepts

5. **Hobbies & Extracurriculars**:
   - Outdoor Sports: **Cricket & Football** (Team player & active sports enthusiast)
   - Indoor/Gaming: **Free Fire** (Tactical strategy, squad reflexes)

6. **Contact & Connect**:
   - Direct interactive links for Email, LinkedIn, GitHub, and college location.
   - Interactive working contact message simulation form.

## 💻 How to Run / View

Simply open `index.html` in any web browser:
- Double click `index.html` directly from your file manager, OR
- Right-click `index.html` > "Open with" > Chrome / Edge / Firefox, OR
- Use the VS Code Live Server extension.
